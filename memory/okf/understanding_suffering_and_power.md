# Understanding Suffering And Power

## Verbatim Discourse Excerpts
So, all these principles are right, but there's so much that we as human beings can do. There's so much that we as human beings can change, and that's possible when we awaken to this powerful state of peace.

As long as we, the human species, live, I'm sure we will have all these problems. We are masters at creating problems. Where there is no problem, we can create a problem, and as long as we are going to be in an unawakened state, we can create more problems.

## Key Teachings
- As long as we, the human species, live, I'm sure we will have all these problems. — Sri Preethaji & Sri Krishnaji
- Where there is no problem, we can create a problem, and as long as we are going to be in an unawakened state, we can create more problems. — Sri Preethaji & Sri Krishnaji
- Where there is peace, there will also be violence. — Sri Preethaji & Sri Krishnaji
